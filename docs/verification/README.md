## 结果边界

原生按钮测试向隔离窗口发送 Windows 鼠标消息，欢迎页检查测量实际布局边界。它们覆盖逻辑、命中和几何，不覆盖真实鼠标、显示器像素或字体观感。

本机自动化不代表 Linux CI、更多 Windows build、跨 DPI、不同 GPU、物理输入法、Narrator、系统高对比度、长时间资源稳定性或干净机器运行已经完成。未执行项目保持未验证状态。

## 验收要求

新增改动应先运行对应的最小检查，再完成相关构建和集成验证。保留失败报告，标明失败发生在修改前、修改后还是环境条件中；不提高超时或句柄容差来掩盖失败。

涉及关闭、启动和资源所有权的修改必须覆盖正常退出、主动关闭、创建期间关闭、输入/输出阻塞、视图失败和再次创建。配置修改必须覆盖有效输入、非法输入、未知版本、外部编辑冲突和原文件保护。
