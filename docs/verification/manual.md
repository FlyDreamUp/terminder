# 人工验收

本清单用于自动化无法完整覆盖的真实设备和交互行为。开始前记录 Windows build、GPU/驱动、显示缩放、键盘布局、输入法、程序 SHA-256 和配置。使用正式便携包验收分发，使用诊断构建定位问题。

不要用有未保存工作的真实 Shell 测试关闭、恢复或故障路径。每项记录操作、预期、实测、是否通过和相关日志；未执行不得标为通过。

| 场景 | 操作与预期 |
| --- | --- |
| 欢迎页 | 普通启动无终端；主页只有一个「新建终端」下拉按钮，先选择 Shell 才创建；菜单就近弹出，窄窗口不越界；设置独立打开；关闭最后一个标签或窗格返回欢迎页；窗口 X 退出 |
| Shell | 分别启动 PowerShell 7、Windows PowerShell、cmd、自定义程序；缺程序、无权限或无效目录提示原因 |
| 输入法 | 中文组合、候选窗、撤销和 Enter 提交；中文/emoji 混合选区不截断；切换窗格后输入不串到原窗格 |
| 键盘 | 工作区快捷键、Ctrl+C、Alt、F1–F12、Tab/Shift+Tab；文本框和终端焦点正确；覆盖不同键盘布局 |
| 选择与粘贴 | 拖选、双击词、三击行；选区 Ctrl+C/右键复制并清除选区，Ctrl+Shift+C 复制并保留；空选区 Ctrl+C 中断、右键粘贴；中文/emoji 实际系统剪贴板读回；剪贴板占用时提示失败、保留选区并可重试；多行粘贴确认/取消；超过容量完整拒绝 |
| 显示 | ANSI 颜色、宽字符、组合字符、动态颜色、光标、备用屏幕和历史滚动；检查字体与背景对比 |
| TUI 鼠标 | 实际鼠标程序中的按下、释放、拖动和滚轮；Shift 允许本地选择；焦点报告正确 |
| 标签与分屏 | 两方向嵌套、分隔线拖动、8 窗格边界、选中边框；每个 X 只关闭自身；保留其他会话 |
| 终端菜单 | 点击「+」只展开菜单，选择类型后创建一个新标签；再次点击「+」、点击外部或 Escape 收起；上下键/Enter；Ctrl+Shift+T 直接创建默认终端；多标签和窄窗口中菜单贴近按钮且不越界；长名称、空列表和 64 项滚动 |
| 搜索与重命名 | 中文正则、非法正则、历史匹配、前后查找；名称留空回到终端标题；80 字符边界 |
| 设置 | 深/浅/系统主题、字体缺失、字号和历史边界；保存失败不丢原配置；外部编辑冲突可见 |
| 关闭与重启 | 自然退出保留网格；运行中确认/取消；已结束会话原位重启；设置保存期间关闭等待保存完成 |
| 恢复 | 默认关闭；启用后询问；取消留欢迎页；恢复布局、活动位置和启动目录；部分或全部条目失效仍可操作 |
| 数据故障 | 无效 TOML/JSON、未知 schema、超大文件、只读目录、双实例写入冲突；原文件和有效备份受保护 |
| 窗口与 DPI | 标题栏拖动、双击、最小化、最大化/还原、关闭；600×400；100/125/150/200% 缩放和跨屏 |
| 可访问性 | 纯键盘、Narrator、系统高对比度；名称、焦点和状态能够被发现 |
| 资源稳定性 | 重复启动关闭、同时输出、长期运行和宿主异常退出；记录句柄、线程、内存和完整尾部 |
| 干净机器 | Windows 10/11 x64、不同 GPU、无开发工具；完整解压、运行库、字体、启动、退出和许可证文件 |
