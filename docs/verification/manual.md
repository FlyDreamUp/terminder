## 性能记录方法

固定 120×40 视口、5000 行历史，区分 PTY 读取、JS 收到、xterm write callback 与实际绘制时间。Rust/JS 摘要比较针对同一 ConPTY 字节流，不能把子程序 stdout 原文当作 ConPTY 输出预期。

记录空闲与 8 会话的宿主/WebView 私有内存、Shell 内存、60 秒空闲 CPU；5 MiB/s 持续 60 秒及另一个会话输入 p95；30 分钟持续/间歇负载与 100 次创建/关闭。DOM 与 WebGL 分开报告，ACK 只代表解析，不代表像素显示。未经测量不得填写性能目标已达成。
